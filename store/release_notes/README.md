# Release notes (first closed beta)

Play Console → **Testing → Closed testing → Create new release → Release notes**.
Use **Add languages** and paste the matching file. English (`en-US`) is the
default and is required.

Play limits release notes to **500 characters per language**; every file here
is under that limit.

## What the notes say

- First closed beta release.
- Highlights: habits with streaks and a monthly calendar, the five prayers
  with times/reminders/widget, Tasbeeh with presets/colors/patterns,
  statistics, backup and restore, 9 languages.
- Reassures testers: no account, no ads, no tracking, data stays on device.
- Asks for feedback at grapplinghook73@proton.me.

## For the next release

Keep the same file names and replace the contents; bump `versionCode` in
`pubspec.yaml` first. Play keeps older release notes in the release history,
so each new release needs its own text.
